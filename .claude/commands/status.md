Read `TARGETS.md`, `DEADLINES.md`, every file in `applications/` and `drafts/`, and
`GAPS.md` if it exists. Run `tools/count.sh` for the real draft state rather than
reading the counts written in the files, which go stale. Report in under 300 words. No
file dumps.

## Report

**Next deadline.** What is due, when, and how many days out. If several land the same
day, say so.

**A table**, one row per org:

| Org | Type | Questions extracted | Drafted | `[NEED:]` open | Deadline |
| --- | ---- | ------------------- | ------- | -------------- | -------- |

**Blocked, and by what.** Split into what is blocked on them (an unanswered gap, a
decision, a document only they can make, a conversation with another person) and what
is blocked on you. Be specific: "RISE is blocked on question 2 in GAPS.md."

**Anything blocked on a third party** gets called out separately, because those have
lead time and the applicant tends to forget them until the deadline. Recommenders are
the usual case: check `you/RECOMMENDERS.md` and report any letter not confirmed
submitted, since a portal does not always tell the applicant.

**Unverified deadlines.** Any date in `DEADLINES.md` not confirmed against a live
source, listed so they can check.

**The one thing to do next**, named specifically. Not a list. One thing, with the
reason it comes before the others.

If a deadline is inside 48 hours and its application is not drafted, lead with that
and say it plainly.
